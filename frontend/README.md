# React + Vite

This template gives a minimal setup to run React in Vite, with HMR and some Oxlint rules. HMR (hot module replacement) updates the page each time that you save a file.

Two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

This template does not enable the React Compiler, because it makes development and builds slower. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

For a production application, use TypeScript with type-aware lint rules. The [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) shows how to add TypeScript and the TypeScript rules of Oxlint to your project.
